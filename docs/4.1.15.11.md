# 微信 4.1.15.11

Windows x64。以下为旧版已实现功能及本机验证范围，不表示当前发布的 4.1.15.53 DLL 可以在旧版运行。

## 已实现功能

| 功能 | 已验证范围 |
| --- | --- |
| 中文、emoji、换行文本 | 中文、emoji、换行；正文与本地聊天气泡一致。 |
| 长文本 | 8192 字节 UTF-8 文本；原生正文匹配，界面首尾标记可见。 |
| 同一微信进程连续独立发送 | 同一进程连续执行三个独立请求，保留请求历史，无重复派发。 |
| 当前账号资料与登录状态 | 当前登录账号 ID、别名、昵称及登录状态读取。 |
| 指定测试联系人发送 | 指定联系人的原生文本发送，本地对应会话显示一致。 |
| 指定测试群发送 | 指定群聊的原生文本发送，本地对应会话显示一致。 |
| 新消息回调 | 原生新消息事件；会话、消息 ID、方向及正文与当前账号数据库匹配。 |
| 联系人查询 | 已加载联系人缓存查询，支持原生 ID、别名、名称；不是远端完整通讯录。 |
| 会话列表 | 当前原生会话摘要缓存枚举，核对正文及时间；不保证界面置顶排序。 |
| 群成员查询 | 指定群的本地缓存成员枚举及联系人名称关联，不包含远端刷新。 |
| 消息历史查询 | 本地消息历史查询、游标分页、Zstd 正文解码，包含长文本。 |
| 关联消息的最终状态查询 | 关联已登记请求与本机成功消息记录；不代表对方送达或已读。 |
| 数据库列表及只读查询 | 当前账号数据库文件枚举；联系人、会话和消息库的认证只读快照 SQL 查询。 |
| 发送图片 | 图片原生发送；消息类型、MD5、大小、尺寸及本地气泡匹配。 |
| 发送文件 | 文件原生发送；文件名、MD5、大小及本地文件卡片匹配。 |
| 普通及 XML 消息转发 | 原生转发文字和文件卡片，不是复制正文重发，也不是任意 XML 发送。 |
| 引用回复 | 原生引用回复，type49/subtype57；原消息字段及本地引用块匹配。 |
| 群内 @ | 指定群内 @ 成员，原生字段、数据库 atuserlist 与发送方界面一致；不确认对方提醒。 |
| 图片解码 | 当前账号 V2 图片缓存：PNG 字节还原及 JPEG 缩略图解码。 |
| 原生视频发送 | H.264 MP4 原生发送；已记录 2 秒视频及本地 type43/status2。 |
| 原生 GIF 表情发送 | GIF 原生发送及转发，按 type47/status2 落库。 |
| 原生网页卡片发送 | 独立网页卡片发送及转发，字段一致，按 status2 落库。 |
| 音乐卡片发送 | 本机发送成功并生成本地消息记录。 |
| 音乐原消息转发 | 本机转发成功并生成本地消息记录。 |

发送结果以本机原生调用、数据库记录和本地界面核对为准，不等同于接收方送达或已读。查询、SQL、解码及界面展示包含调用端能力，不应理解为全部由一个 DLL 提供。

旧版接收链已有新入站文本与当前账号数据库精确关联的记录，并非只读取历史消息。自动回复调用端也保留了文本回复的本机成功记录；它依赖接收链、模型服务及发送链，不是 DLL 自带的模型功能。

## 偏移

模块：`Weixin.dll`。SHA-256：`7d056cf7fb834b5558d6646bfb4e0036aae93568e3f9a04cf1dfc5e79032bcac`。

RVA 以当前进程的 `Weixin.dll` 基址为起点，不是磁盘文件偏移。虚表地址不是函数入口。模块指纹不一致时不能沿用这些数值。

### 对象内字段与类型

| 字段 | 对象内偏移或值 |
| --- | --- |
| 文本收件人 | source `+0xB0` |
| 文本消息类型 | source `+0x118`，值 `1` |
| 文本正文 | source `+0x758` |
| 群内 @ 成员串 | source `+0x778` |
| 引用原消息记录 | source `+0x248` |
| 音乐消息类型 | `0x300000031`，类型值而非地址 |

这些字段属于对应消息对象，不能套用到其他结构。调用仍需匹配原生线程、参数布局、对象生命周期及结果处理。
