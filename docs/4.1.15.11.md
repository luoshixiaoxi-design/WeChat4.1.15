# 微信 4.1.15.11

Windows x64。已实现并有本机成功记录的功能如下：

| 功能 | 确认范围 |
| --- | --- |
| 音乐卡片发送 | 本机发送成功并生成本地消息记录 |
| 音乐原消息转发 | 本机转发成功并生成本地消息记录 |

## 已实现路径的偏移

适用模块：`Weixin.dll`，SHA-256：`7d056cf7fb834b5558d6646bfb4e0036aae93568e3f9a04cf1dfc5e79032bcac`。

| 用途 | 类型 | 数值 |
| --- | --- | --- |
| 音乐卡片对象工厂 | Weixin.dll RVA | `0x55B7F80` |
| 音乐控制块虚表 | Weixin.dll RVA | `0x981F688` |
| 音乐消息对象虚表 | Weixin.dll RVA | `0x981F718` |
| 音乐消息类型 | 类型值，非地址 | `0x300000031` |

上述地址来自旧版音乐消息实现。音乐发送和音乐原消息转发均有本机成功及落库记录；不扩展为所有消息类型转发，也不代表接收方确认送达。

RVA 以当前进程的 `Weixin.dll` 基址为起点；虚表地址不是可直接调用的函数。类型值只用于识别消息，不参与地址计算。模块指纹不一致时不能沿用这些数值。
