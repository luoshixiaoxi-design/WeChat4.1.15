# WeChat4.1.15

Windows x64 微信原生功能 DLL。按微信版本区分模块，仅提供二进制文件和使用说明，不提供源码。

## 版本

| 微信版本 | 发布范围 | 说明 |
| --- | --- | --- |
| 4.1.15.53 | DLL | [功能与文件清单](docs/4.1.15.53.md) |
| 4.1.15.11 | 已实现功能与偏移 | [旧版说明](docs/4.1.15.11.md)；本次不提供该版本 DLL |

两版不能混用 DLL。4.1.15.11 的既有记录不表示 4.1.15.53 的全部功能也支持旧版。

旧版功能还包括文本收发、联系人与会话查询、历史及只读 SQL、图片/文件/视频/GIF 发送、转发、引用和群内 @；详见[旧版完整说明](docs/4.1.15.11.md)。

## 下载

DLL 位于 [dll/4.1.15.53](dll/4.1.15.53)。下载后可按 [SHA-256 清单](docs/CHECKSUMS.md) 核对文件。

这是按功能拆分的原生模块，不是可以双击运行的程序，也不是完整 SDK。调用端需要实现对应请求协议、会话校验和结果读取。仓库不附带工作台、加载器、HTTP 服务、WebSocket 服务或自动回复服务；不能直接使用 wxbot 的接口地址调用这些 DLL。

## 功能

- 文本、图片、视频、SILK 语音、文件、GIF 动态表情。
- 网页卡片、音乐卡片、普通联系人名片。
- 网页卡片原消息转发、文字收藏转发、引用回复。
- 本人文字消息撤回、图片添加为表情。
- 新入站文本捕获、联系人资料查询、联系人标签修改。

各功能的格式及验证范围见对应版本文档。发送成功记录来自本机原生调用和本地消息记录，不等同于接收方设备确认送达。
